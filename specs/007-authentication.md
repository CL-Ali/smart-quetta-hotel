# 007 Authentication

## Guest Authentication

- Signed guest browser session cookie or equivalent token
- No password required
- Identity is scoped to a guest plus visit plus browser context

## Recovery Identity

- Ticket number
- QR token
- Phone lookup
- Staff assisted lookup

## Staff Authentication

- JWT access token
- Refresh token support
- Role-based access control

## Roles

- admin
- cashier
- kitchen
- waiter
