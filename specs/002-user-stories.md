# 002 User Stories

## Customer

As a guest, I want to open the captive portal so I can start a visit quickly.

As a guest, I want to resume my visit after browser reset so I can continue ordering.

As a guest, I want to add items to my cart multiple times so I can place more than one order during a visit.

## Kitchen

As kitchen staff, I want to see live incoming orders so I can start cooking immediately.

As kitchen staff, I want to move orders through clear status steps so the queue stays accurate.

## Cashier

As a cashier, I want to generate an invoice and receipt from a visit so I can close the bill cleanly.

As a cashier, I want to record payment methods and partial payments so the settlement matches reality.

## Admin

As an admin, I want menu and category management so I can keep the catalog current.

As an admin, I want reports and settings so I can manage the restaurant from one place.
