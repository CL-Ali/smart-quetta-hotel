# AI Working Agreement

The specs/ directory is the single source of truth.

## Workflow

1. Read specs.
2. Create implementation plan.
3. Wait for approval.
4. Analyze one file.
5. Modify one file.
6. Self-review.
7. Wait for approval.
8. Continue.

## Rules

- Never rewrite working code.
- Never change unrelated files.
- Never skip acceptance criteria.
- Never implement multiple phases together.
- Stop if the specs conflict.
- Keep commits small.
